KBuild Network - Role Testing Build

This build temporarily disables SMS OTP for testing only.
On launch, choose:
1. Customer
2. Service Provider / Partner
3. Admin

The selected role is stored locally on the device until Logout.
Real Supabase/Twilio OTP is intentionally not used in this testing build.

After the role UI and workflows are verified, OTP can be re-enabled without redesigning the three interfaces.
